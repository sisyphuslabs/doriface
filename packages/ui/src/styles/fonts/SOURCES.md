# Terminal fonts

Cut from upstream releases with fontTools `pyftsubset` (`--flavor=woff2 --layout-features=*`). Each `@font-face` in
`../terminal-fonts.css` lists exactly the characters its file holds.

| File                                       | Upstream                                                                        | License                                | Characters                                                                                                                                                  |
| ------------------------------------------ | ------------------------------------------------------------------------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `jetbrains-mono-symbols-wght-normal.woff2` | JetBrains Mono 2.304, `fonts/variable/JetBrainsMono[wght].ttf`                  | OFL 1.1 (`LICENSE-jetbrains-mono.txt`) | every character of the font outside the Fontsource subsets in `@fontsource-variable/jetbrains-mono` 5.3.0                                                   |
| `symbols-nerd-font-mono.woff2`             | Nerd Fonts 3.5.1, `NerdFontsSymbolsOnly.zip`, `SymbolsNerdFontMono-Regular.ttf` | MIT (`LICENSE-symbols-nerd-font.txt`)  | the whole font                                                                                                                                              |
| `noto-sans-symbols-2-terminal.woff2`       | google/fonts `ofl/notosanssymbols2/NotoSansSymbols2-Regular.ttf`                | OFL 1.1 (`LICENSE-noto.txt`)           | arrows, math operators, technical, enclosed, geometric, symbols, dingbats, braille and supplemental arrows/math (U+2190-2BFF blocks) neither face above has |
| `noto-sans-symbols-terminal.woff2`         | google/fonts `ofl/notosanssymbols/NotoSansSymbols[wght].ttf`                    | OFL 1.1                                | the same blocks, what the faces above still lack (e.g. U+23BF)                                                                                              |
| `noto-sans-math-terminal.woff2`            | google/fonts `ofl/notosansmath/NotoSansMath-Regular.ttf`                        | OFL 1.1                                | the same blocks, what the faces above still lack (e.g. U+21B5, U+29C9)                                                                                      |
