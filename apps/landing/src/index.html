Your terminals and coding agents, on every screen.

Doriterm is a browser, PWA and desktop client for the terminals and agents running on your own machines. What crosses the network is a Noise session; the relay in the middle forwards records it cannot read.

A workspace, not a remote desktop.

Every pane is a real terminal on a real machine, drawn by libghostty-vt in your browser. Doriterm passes herdr-core's own protocol through byte for byte, so every hc method works here as it does there.

One workspace on every screen

The same tabs, panes and layout in a browser tab, on a phone as an installed app, and in the desktop app. Start something at your desk and answer it from the train.

Agents that say when they need you

The sidebar groups every session as needs you, working, idle, done or offline, so you read a list instead of cycling through panes looking for the one that stopped.

One window, many machines

Add a machine over ssh, or through the relay with hc machine add --via. Its terminals appear beside your local ones as b/t1, b/t2, each with its own reconnect, in the same list.

An encrypted pipe, not a proxy

Each client holds its own Noise session with its host — IKpsk2 with the pairing code's preshared key the first time, IK after that — and a ChaCha20-Poly1305 record layer that rekeys every 220 messages. The relay forwards records it can drop, delay or reorder, and never read, forge or splice.

client Noise_IKpsk2_25519_ChaChaPoly_BLAKE2s
relay forwards records it cannot read
host Noise_IK_25519_ChaChaPoly_BLAKE2s

Pair once, then join a mesh the same way

The host prints a link, a QR code, an eight-character code and a fingerprint. The code is single use and dies after ten minutes. mesh pair opens the same kind of single-use offer for another machine to join this one's mesh. 

$ doriface-host pair          # a link, a QR code, a typed code and a fingerprint
$ doriface-host mesh pair     # a single-use offer for another machine to join
$ doriface-host connect <link> < /dev/null   # once, on the other computer

Three pieces, one session.

  1. 01

    Run a host

    On the machine whose terminals you want. The desktop app starts one when it opens; otherwise run doriface-host, which speaks to herdr-core (hc) on that machine.

  2. 02

    Open a client

    app.doriterm.com in a browser, installed on a phone as an app, or the desktop app on any of your computers.

  3. 03

    Pair it once

    Scan the QR code or open the link the host printed, then confirm the fingerprint. After that the client and the host meet through the relay, encrypted end to end.

The relay sees ciphertext only.

Noise, not a proxy

IKpsk2 for the first session with a pairing code's preshared key, IK afterwards, over ChaCha20-Poly1305 records that rekey every 220 messages. The relay can drop, delay or reorder records — the session then fails — but it cannot read or forge one.

Keys stay on your machines

The host's Ed25519 identity and X25519 static live in its state directory, mode 0600, beside the paired-device store. The web client's device key is non-extractable wherever WebCrypto allows it.

What the relay does see

Addresses, timing and sizes, session ids, the pairing slots and their public keys, and — for the machine-to-machine dials a host proves with a relay pass — which host dialled which.

Desktop app

The app starts the host and hc on the machine it runs on, restarts the host if it stops, and installs herdr-core for this user when it is missing or too old.
